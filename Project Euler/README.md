# Project Euler

A record of my early solutions to Project Euler problems.

The problems were useful for practising the translation of mathematical reasoning into code, particularly around iteration, divisibility, prime numbers, sequences and computational efficiency.

## What this folder contains

The repository currently contains solutions to the first set of problems I worked through, with each question kept in its own folder.

These solutions are deliberately preserved as part of the learning history of the repository rather than presented as polished competitive-programming solutions.

## What I learned

Working through these problems helped me develop habits that still appear in my newer projects:

- breaking mathematical problems into smaller computational steps;
- looking for structure before writing a brute-force solution;
- thinking about how the number of operations grows with the input;
- testing assumptions against small examples;
- turning mathematical patterns into reusable algorithms.
