# Roblox Development

Older Roblox/Luau experiments from an earlier stage of my programming development.

These projects were where I first became interested in building interactive systems and understanding how different pieces of software communicate. The code covers several small gameplay and scripting systems rather than one finished game.

## Examples

- **Player data** — persistent player information and DataStore-related logic.
- **Dialogues** — scripted dialogue systems and interactions.
- **Flashlight** — gameplay behaviour and client-side effects.
- **Lightning** — visual/gameplay effects.
- **Module scripts** — experimenting with reusable Luau modules.
- **Number formatting** — utility code for presenting numerical values.

## What I learned

Roblox introduced me to concepts that became useful well beyond game development:

- separating reusable logic into modules;
- working with client/server boundaries;
- handling events and state;
- structuring code into independent systems;
- debugging behaviour in an interactive environment.

## Status

**Archived learning work.** The code is retained as a record of my development history and is not maintained as a current Roblox project.

My current projects use more structured repositories and focus on systems programming, cybersecurity, machine learning and software engineering.
