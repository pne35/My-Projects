# Roblox Code Archive

A collection of small Luau scripts and systems developed while learning Roblox Studio.

The files cover several independent experiments rather than a single application. They are kept here as examples of earlier work with scripting, game state, modules, events and gameplay effects.

## Included examples

| Area | What it explores |
|---|---|
| `PlayerData` | Player state and persistent data |
| `Dialogues` | Dialogue and interaction logic |
| `Flashlight` | Gameplay mechanics and effects |
| `Lightning` | Visual/gameplay effects |
| `Use of module scripts` | Reusable Luau modules |
| `Use of formating number` | Number-formatting utility code |

The naming and structure reflect the age of these experiments, so this folder should be treated as an archive rather than a current codebase.
