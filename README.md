# My Projects

A collection of projects from my earlier development work, kept as a record of how my interests and programming skills developed over time.

This repository is intentionally different from my current flagship projects: it contains smaller experiments, algorithmic exercises and older Roblox development rather than polished production software.

## Projects

### 🔐 [RSA — From First Principles](./RSA)
A small Python implementation of the RSA public-key cryptosystem, built to understand the mathematics behind public-key encryption rather than relying on a cryptography library.

**Topics:** number theory · modular arithmetic · Extended Euclidean Algorithm · modular inverses · RSA

### 🧮 [Project Euler](./Project%20Euler)
Solutions to early Project Euler problems. These are mainly exercises in translating mathematical ideas into algorithms and improving computational approaches.

**Topics:** algorithms · problem solving · mathematics · computational thinking

### 🎮 [Roblox](./Roblox)
Older Roblox/Luau experiments covering systems such as player data, dialogue, module scripts, effects and other gameplay mechanics.

**Topics:** Lua/Luau · Roblox Studio · client/server scripting · modules · game systems

## Why this repository exists

Some of these projects are several years old and are not intended to represent my current engineering standards. I have kept them because they show the progression from small programming experiments towards more structured projects.

My current work is maintained in separate repositories and focuses more heavily on systems programming, cybersecurity, machine learning and software engineering.

## Repository status

This is primarily a **development archive and learning record**. Individual projects may be incomplete, simplified or dependent on the tools available when they were written.

For current work, see the featured projects on my GitHub profile.
